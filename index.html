ABOUT ONION PROJECT

หัวหอม (Onion Project)

ระบบค้นหาหนังและซีรีส์ตามความรู้สึก

หัวหอม (Onion) คือระบบที่ช่วยให้ผู้ใช้ค้นหาหนังและซีรีส์จากสิ่งที่กำลังรู้สึก ความต้องการ หรือสถานการณ์ที่พบเจอ โดยไม่จำเป็นต้องรู้ชื่อเรื่องล่วงหน้า

เพียงบอกหัวหอมว่า “วันนี้เหนื่อย อยากดูอะไรตลก ๆ” หรือ “อยากดูซีรีส์โรแมนติกอบอุ่นหัวใจ” ระบบจะค้นหาข้อมูลที่เกี่ยวข้องจาก Dataset และจัดอันดับเรื่องที่เหมาะกับคุณ

“ไม่รู้จะดูอะไร?
แค่บอกความรู้สึก
เดี๋ยวหัวหอมช่วยเลือกให้” 💜
🎯
THE PROBLEM

ปัญหาที่หัวหอมต้องการแก้

ช่วยให้การเลือกหนังและซีรีส์ง่ายขึ้นในวันที่ไม่รู้จะดูอะไร

🤔

ไม่รู้จะดูอะไร

ผู้ใช้มีเวลาว่าง แต่อาจไม่รู้ว่าจะเลือกหนังหรือซีรีส์เรื่องไหนดี

🔎

ค้นหาด้วยชื่อเรื่องไม่ได้เสมอไป

บางครั้งเรารู้เพียงความรู้สึกหรืออารมณ์ แต่ไม่รู้ชื่อเรื่องที่ต้องการ

🎬

มีตัวเลือกจำนวนมาก

เมื่อมีเนื้อหาจำนวนมาก การเลือกด้วยตัวเองอาจใช้เวลาและตัดสินใจยาก

💡 หัวหอมจึงเปลี่ยนการค้นหาจาก “จำชื่อเรื่องให้ได้” เป็น “บอกความรู้สึกและความต้องการ”
🔎
INFORMATION RETRIEVAL

Information Retrieval (IR) คืออะไร?

Information Retrieval หรือ IR คือกระบวนการค้นหาและนำข้อมูลที่เกี่ยวข้องกับความต้องการของผู้ใช้มากที่สุดออกมาจากชุดข้อมูลจำนวนมาก

สำหรับ Onion Project ระบบ IR จะนำข้อความที่ผู้ใช้พิมพ์ไปเปรียบเทียบกับข้อมูลของหนังและซีรีส์ เช่น ชื่อเรื่อง ประเภท หมวดหมู่ Mood Theme Situation Keywords และ Description จากนั้นคำนวณความเกี่ยวข้องและจัดอันดับผลลัพธ์

👤ผู้ใช้พิมพ์ความต้องการ“วันนี้เหนื่อย อยากดูอะไรตลก ๆ”

HOW THE SYSTEM WORKS

เทคนิคที่ใช้ในระบบ

หัวใจสำคัญของการค้นหาและจัดอันดับข้อมูล

📄TF-IDF

วิเคราะห์และวัดความสำคัญของคำที่ปรากฏในข้อมูลหนังและซีรีส์

📐Cosine Similarity

วัดความคล้ายกันระหว่างคำค้นของผู้ใช้กับข้อมูลแต่ละเรื่อง

🏆Ranking

เรียงลำดับผลลัพธ์จากเรื่องที่มีความเกี่ยวข้องมากที่สุด

🎯Information Retrieval

กระบวนการค้นหา เปรียบเทียบ และคืนข้อมูลที่ตรงกับความต้องการ
